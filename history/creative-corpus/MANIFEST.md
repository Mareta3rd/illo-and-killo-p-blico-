# Historical Creative Corpus — Origins / Illo & Killo

**Status: HISTORICAL DEVELOPMENT MATERIAL — NOT CURRENT CANON.**

This corpus preserves previously developed images as visual, narrative and technical reference material. It must not be interpreted as the current character design, current gag canon, current model sheets, or current asset library.

## Creative lineage

The project has passed through three distinct creative stages:

1. **Origins** — the earliest eight-image exploration. This stage contains an earlier character treatment, including literal horse/bull readings and other decisions that were later abandoned. It is historical source material only.
2. **Illo & Killo** — the subsequent working stage immediately preceding the current project. This stage contains the espeto/fishing and jamón/mosquito images. It is the direct historical predecessor of the current project and contains useful accumulated work, but it is not current canon.
3. **Arsa & Pisha** — the current project and current creative canon. It is an evolved stage, not a simple rename of either historical stage.

A small, controlled vintage/print-comic soul may be retained as an aesthetic homage to the development lineage, but the current visual target remains contemporary, high-quality and forward-looking. Historical visual styles must not be reintroduced wholesale.

## Naming rule

Semantic filenames are descriptive indexes, not new canon. The original numeric generation ID is always retained as the final filename component. Classification is based on visible **content + gag/mechanism**, not guessed chronology.

Names deliberately avoid treating transitional lettering such as `ARSA Y PISHA` inside an old image as proof that the image itself is current canon. The archive records what the image contains, while the current canon is defined elsewhere.

## How to use

These images may be used to:
- study the project's visual evolution;
- identify successful gag mechanisms, compositions, poses, expressions and graphic devices;
- compare historical and current character treatment;
- recover useful ideas only after revalidation against current Arsa & Pisha canon;
- understand the origin of the restrained vintage/print-comic accent in the current visual direction.

These images must not be used to:
- reintroduce historical names or designs automatically;
- override `data/characters.yaml` or other current canonical sources;
- establish historical anatomy, proportions, typography, palettes, props or styling as current invariants;
- treat an old image as a canonical reference image;
- treat Origins as an earlier version of the current Arsa & Pisha design;
- treat Illo & Killo as the current project identity.

## Current interpretation

The archive is deliberately additive. Preserving old work does not mean preserving every decision contained in it. A historical image can contain a successful gag mechanism, pose, composition, joke, visual rhythm or production lesson while its character design or terminology is obsolete.

Historical material becomes usable creative input only after explicit comparison and revalidation against the current Arsa & Pisha canon.
