# Prompt de model sheet · Arsa & Pisha

Genera una hoja de modelo canónica de **Arsa** o **Pisha** desde los datos canónicos actuales. No reinterpretar libremente la identidad; documentarla de forma útil para producción.

## Reglas
- Usar el canon estructurado y los model sheets actuales como autoridad.
- Mostrar vistas útiles para producción: frontal, perfil, tres cuartos y espalda.
- Distinguir claramente brazos/manos de piernas/pezuñas.
- Mantener silueta, proporciones, rasgos identitarios y anatomía estilizada establecidos.
- Las expresiones y poses pueden variar para documentar comportamiento sin alterar identidad.
- No trasladar automáticamente nombres, rasgos, proporciones o diseños del corpus histórico de Illo & Killo/Xoxo.
- El acabado debe ser contemporáneo y de alta calidad; el toque vintage/tebeo, cuando exista, debe ser sutil y nunca dominar la identidad.

## Objetivo
Documentar con precisión a Arsa & Pisha para ilustración, gags, merchandising, 3D y futuras referencias generativas, preservando identidad semántica antes que reproducción pixel a pixel.
