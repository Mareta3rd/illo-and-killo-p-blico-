# Operating Sequence

## Purpose
Define the practical order of operations for using SinergYa Core with Illo & Killo as the first content base.

## Sequence
1. Start with an idea.
2. Use `recommend_route` to determine the best route.
3. Use `generate_brief` to create a structured brief.
4. Use `build_prompt` to create the final production prompt.
5. Generate the piece.
6. Use `validate_piece` to check canon and production fit.
7. Use `run_tests` to evaluate the result formally.
8. If needed, send the work back to Lab.
9. If exploratory, keep it in Playground.
10. If approved, promote to Canon and/or Production.

## Human intervention
Escalate to human review when a change would affect canon, introduce a new invariant, or create a major strategic decision.

## Goal
Keep the system simple at the point of use while preserving strong internal structure.
